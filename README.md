# 📦 Xpressio - Your Online Everything Store

**Xpressio** is a modern, fast, and user-friendly e-commerce platform where fashion, electronics, and groceries—everything is available at great prices. It is designed with "express delivery" and "premium shopping experience" in mind.

---

## 🚀 Key Features

- **Multi-Category Support:** Fashion, Electronics, Grocery, Home Decor, and more.
- **Smart Search:** Intuitive search bar with real-time filtering.
- **Responsive UI:** Fully optimized for Mobile, Tablet, and Desktop views.
- **Modern Authentication:** Secure login/signup system (Firebase/JWT).
- **Cart Management:** Dynamic add-to-cart, quantity updates, and persistent storage.
- **Wishlist:** Save your favorite items for later.
- **Admin Dashboard:** Manage products, orders, and users efficiently.

## 🎨 Branding & Design

- **Name:** Xpressio (Express + Expression)
- **Tagline:** Everything You Need, Fast.
- **Primary Color:** Electric Blue (`#2563EB`)
- **Secondary Color:** Deep Purple (`#7C3AED`)
- **UI/UX:** Built following the 8pt Grid System in Figma for pixel-perfect precision.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, React Router,React Icons, Framer Motion,daisyUI,swiper,React Toastify,React Helmet,FireBase,React Spinners
- **State Management:** Redux Toolkit / Context API
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / Firebase
- **Deployment:** Vercel / Netlify
